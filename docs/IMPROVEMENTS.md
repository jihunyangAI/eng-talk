# 개선점 목록

작성: 2026-11-07 · 상태 표시: ☐ 할 일 / ◐ 진행 중 / ☑ 완료

## 추천 우선순위

1. ☐ 학습 기록 저장 + 홈 화면 진도 표시
2. ☐ 재생 속도 조절 + 내 목소리 녹음해서 다시 듣기
3. ☐ 태국어 번역 원어민 검수
4. ☐ 챕터별 핵심 표현 정리
5. ☐ 디자인 정체성(로고·색·글꼴) + 홈 화면 개편

---

## 1. 학습 기능

| 상태 | 개선점 | 현재 | 제안 | 효과 | 작업량 |
|---|---|---|---|---|---|
| ☐ | 학습 기록 | 체험 점수가 새로고침하면 사라짐 | 챕터별 최고 점수·완료 여부 저장, 목록에 ✅와 점수 표시 | ★★★ | 작음 |
| ☐ | 내 목소리 다시 듣기 | 점수만 표시 | 내 발음을 녹음해 원어민 음성과 번갈아 듣기 | ★★★ | 중간 |
| ☐ | 재생 속도 조절 | 1배속만 | 0.75배 / 1배 버튼 | ★★★ | 작음 |
| ☐ | 전체 대화 자동 재생 | 한 줄씩 눌러야 함 | ▶ 한 번이면 장면을 넘기며 대화 전체 재생 | ★★ | 작음 |
| ☐ | 쉐도잉 모드 | 없음 | 원어민 문장 듣기 → 따라 말하기 → 점수 (전체 문장 대상) | ★★ | 작음 |
| ☐ | 핵심 표현 정리 | 없음 | 챕터마다 핵심 표현 3~5개와 설명 | ★★★ | 중간 (콘텐츠 작성) |
| ☐ | 복습 | 없음 | 즐겨찾기 문장, 틀렸던 문장만 다시 연습 | ★★ | 중간 |
| ☐ | 힌트 단계 | 영어 전체 보기 / 숨기기뿐 | 숨김 상태에서 첫 단어만 보여주는 힌트 | ★ | 작음 |

## 2. UI·디자인

| 상태 | 개선점 | 현재 | 제안 |
|---|---|---|---|
| ☐ | 홈 화면 | 카드만 나열 | 진도 표시(8개 중 3개 완료), 카테고리(여행·일상·쇼핑), "이어서 학습" 버튼 |
| ☐ | 브랜드 느낌 | 시스템 기본 글꼴, 단색 | 로고·대표 색·글꼴 정하기 |
| ☐ | 체험하기 역할 선택 | 글자만 있음 | 인물 얼굴 사진(장면 사진에서 잘라 쓰기) 추가 |
| ☐ | 말하는 중 표시 | 점 깜빡임 | 마이크 입력 크기에 따라 움직이는 음량 막대 |
| ☐ | 결과 화면 | 점수 목록 | 축하 효과, 이전 기록과 비교("지난번보다 +12%") |
| ☐ | 넓은 화면 레이아웃 | 사진 높이 제한으로 위아래 잘릴 수 있음 | 넓은 화면에서는 사진과 대화를 좌우 배치 |
| ☐ | 다크 모드 | 없음 | 밤 학습용 |
| ☐ | 첫 화면 언어 깜빡임 | 태국어 사용자도 처음 한순간 한국어가 보임 | 언어 설정을 렌더링 전에 적용 |

## 3. 콘텐츠

| 상태 | 개선점 | 설명 |
|---|---|---|
| ☐ | 태국어 번역 검수 | AI가 작성한 번역이라 원어민 확인 필수 (최우선) |
| ☐ | 난이도 | 8개 챕터 모두 초급. 같은 상황의 중급 버전(문제 상황, 긴 문장) 추가 |
| ☐ | 목소리 다양성 | 모든 챕터가 Emily·Mark 두 목소리. 중급부터 다양한 목소리·억양 고려 |
| ☐ | 이야기 연결 | 공항 → 입국 → 택시 → 그랜드 호텔이 한 여행처럼 이어짐. '여행 스토리'로 묶어 표시 |

## 4. 기술·품질

| 상태 | 개선점 | 설명 |
|---|---|---|
| ☐ | GitHub 자동 배포 | 미연결. Vercel 대시보드 → Settings → Git에서 `jihunyangAI/eng-talk` 연결 |
| ☐ | 아이폰 실기기 테스트 | 체험하기에서 상대 음성 자동 재생이 막힐 수 있음. 미확인 |
| ☐ | 채점 테스트 코드 | `lib/scoring.ts`를 수동으로만 확인함. 자동 테스트 추가 |
| ☐ | 발음 채점 정확도 | 현재는 '알아들었나' 기준 근사치. 필요 시 전문 발음평가 API(Azure 등, 유료)로 교체 |
| ☐ | 콘텐츠 제작 자동화 | 음성 연결 스크립트를 저장소 `scripts/`로 옮기고, 챕터 추가 과정을 명령 한 번으로 정리 |
| ☐ | 공유 미리보기 | 링크 공유 시 미리보기 이미지·설명(Open Graph) 없음 |
| ☐ | 사용 통계 | 챕터별 이용·이탈 지점 파악 불가 (Vercel Analytics 무료) |
| ☐ | 접근성 | 단어 정확도를 색으로만 구분, 키보드 이동 일부 미흡 |
